# 💰 Crypto Tracker

A modern cryptocurrency tracking web application that provides real-time information about various cryptocurrencies. Users can search for coins, view current prices, market capitalization, trading volume, and other essential market data through an intuitive interface.

## 🚀 Features

- 📈 Real-time cryptocurrency prices
- 🔍 Search cryptocurrencies by name
- 💹 View market capitalization and trading volume
- 📊 Display price changes (24-hour)
- 📱 Responsive user interface
- ⚡ Fast and user-friendly design

## 🛠️ Technologies Used

- JavaScript
- React.js
- HTML5
- CSS3
- CoinGecko API (or your API if different)
- Node.js
- npm

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Chinnu1818/CryptoTracker.git
```

2. Navigate to the project folder

```bash
cd CryptoTracker
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm start
```

The application will run on:

```
http://localhost:3000
```
